0. 전체 흐름

3. 유도속성
4. 외래키 위치와 Null 여부

6. 서술형 대비: 화면 설계 기반 DB 구축의 문제점과 개선 절차
7. 연습: ERD 그리기
8. 단답 암기 리스트
9. 시험 예시별 모범답안
